# D12 剩余的检测损失是不是泛化问题：训练图对 val，以及与训练集的相似度

日期：2026-11-11。主线诊断。不训练、不改结构；只用 train 和 val，test 不参与。GPU 0、1 用于相似度矩阵和训练图推理。

问题：分数与排序这一侧已经查尽（见 [BCLQ 评审](sardet100k_bclq_design_review.md) 末尾的汇总）。[RegionDense 的 val 拆解](sardet100k_region_dense_val_breakdown.md)又显示，512 来源的 aircraft 一去掉混合增强就大量漏检。这一轮直接检验：基线剩下的损失，是模型**学不会**，还是**学会了但迁移不到新目标**。

## 口径

- **运行：** E000（原 DEIM）、E008（去掉 Mosaic 与 MixUp）、E009（RegionDense），都取第 35 轮 `best_stg2`。
- **训练图对 val：** 同一个检查点，对随机 12,000 张训练图（种子 0，25,038 个 GT）和全部 val（22,703 个 GT）推理。
- **与训练集的相似度 sim：** 每个 GT 的 24×24 裁片，与**另一张训练图**上尺寸相近（长边比在 10% 以内）的任一 GT 裁片的最大相关系数。这就是基线诊断里“见过 / 没见过”的定义（见过 = sim ≥ .9），这里保留为连续值。val 上见过的比例为 57.2%，与此前的数字一致；训练子集内部为 66.5%。
- **检出：** 工作点 score ≥ .3、IoU ≥ .5，按分数贪心匹配。漏检分为“没有框”（任何分数下都没有 IoU ≥ .5 的同类框）和“分数低”。
- **分相似度的 AP：** COCO 口径。范围外的 GT 记为忽略（匹配到它们的检测框也忽略），未匹配的检测框在每个范围内都算误检。E000 的结果与基线诊断完全一致（见过 70.67、没见过 44.48）。
- **单元格：** 训练图没有来源表，所以需要与 val 对照的单元格按“图像尺寸 / 类别”命名；256 图里的 tank 按长边 16 像素分开（< 16 为 OGSOD 样，val 上对 139/140）。
- 代码 `tools/sardet100k/generalisation_gap.py`（similarity / predict / analyse / ap）。服务器输出 `independent_verify_20261106/d12_generalisation/`（git `33172bb`），本地 `analysis_outputs/d12_generalisation/`。单种子。

## 判读

1. **剩余的检出损失主要是泛化问题，不是学不会。** 模型在训练图上漏检不到 1.5%，在 val 上 6%；val 的漏检 80% 落在训练集里没有近重复副本的 43% 目标上。
2. **这不是“这些目标本来就难”。** 训练图上 sim < .9 的三档，合并召回率是 92.5–97.3%（E000）；val 上同样三档只有 71.4–92.0%。难的不是目标本身，而是没见过的目标。
3. **官方 AP 是两个人群的混合。** 见过的目标 AP 70.7，没见过的 44.5，相差 26 点。没见过的 aircraft、tank、bridge 只有 32.5、18.3、30.6。
4. **E008 和 RegionDense 的增益全部来自见过的目标。** 见过的 AP +1.3、+1.6；没见过的 −0.7、−0.3。它们让模型更好地拟合能记住的目标，没有改善泛化。训练图的漏检同步减少（364 → 189 → 160），而 val 的漏检数没有减少。
5. **Dense O2O 的作用因此可以说清楚了：** 对大目标它是对抗记忆的正则化（没见过的 aircraft AP 32.5 对 27.3，召回在 sim .5–.7 档 81.8 对 67.6）；对小目标它把目标缩到像素极限，是有害的（没见过的 tank、bridge 去掉后 +1.9、+3.6）。
6. **两种损失并存，要分开看：**
   - **泛化受限：** 512 / aircraft（训练图 100% → val 91–94%）、800 与 1000 的 ship。训练图完全拟合，损失全在没见过的目标上。
   - **证据也受限：** OGSOD 样的小 tank、bridge。训练图上也只有 91–98%，说明图像证据本身不足；同时仍有 9–14 点的训练图到 val 的落差。
7. **没见过的目标，漏检多数是“有框但分数低”**（sim .5–.9 两档合计 607 对 282）。框找到了，置信度给不出来。这与此前在 SAR-AIRcraft 上看到的现象一致。
8. **没见过的 aircraft 定位也差：** AP75 只有 19.9（见过的 70.7）。它不只是分数问题。

## 对主线的含义

- **问题来源可以明确写成：** SARDet-100K 的切片有重叠，57% 的 val 目标在训练集里有近重复副本；DEIM-M 把这部分记住了（AP 70.7），对其余 43% 的目标泛化很差（AP 44.5）。官方 AP 的提升空间主要在后者。
- **这解释了分数侧为什么查不出东西：** 同一目标的候选之间选谁，对见过的目标已经近乎完美；没见过的目标缺的不是排序，而是可迁移的证据。
- **评价工具已经有了：** 以后每个候选方法除了全 val AP，都报告“没见过的目标”的 AP。只涨见过的那一半，说明方法在帮助记忆。

还没有回答、但决定模块形式的问题：**泛化落差出在表征还是读出？** 即 backbone 与 encoder 的特征对没见过的目标是否仍然可分。如果可分，问题在 decoder 和检测头的记忆，可以在头部做轻量的结构或正则；如果不可分，问题在特征本身，要从骨干或预训练入手。这可以用冻结特征的探针在 GPU 上直接测（D12.2）。

## 局限

- sim 是 24×24 裁片的相关系数，只是“训练集里有没有很像的目标”的近似；阈值 .9 沿用旧定义，没有调过。
- 相似度低的目标可能本身更不典型。第三节用训练图上的同档目标作对照，排除了“本身不可检”，但不能排除它们在别的方面更难（例如定位）。
- 训练图推理没有增强，训练时见到的是增强后的图；训练图召回率是对记忆程度的度量，不是可达到的上限。
- 训练图的单元格按尺寸和类别划分，不是像素比对的来源。
- 单种子、单个检查点。

## D12.2 泛化落差出在特征还是检测头（2026-11-11）

### 口径

- 对每个 GT 框（正样本）和同图里一个同尺寸、与任何 GT 都不重叠的随机框（负样本）取特征。范围是 D12 的 12,000 张训练图和全部 val。
- **四种信号：**

| 名称 | 内容 |
|---|---|
| IMG | 640 输入上的 24×24 灰度裁片（去均值、单位范数）。只看像素能得到什么，作下限 |
| BB | backbone 的 stride 8 / 16 / 32 输出，框内 3×3 采样取平均后拼接 |
| ENC | encoder 的 stride 8 / 16 / 32 输出（各 256 通道），同样的池化 |
| ENC_SCORE | 检测器自己的 encoder 分类 logit：框内各 token、各类别的最大值。不是探针，是训练好的读出 |

- **探针：** 类别无关的线性探针（逻辑回归，目标对背景），只在训练图的三分之二（A）上拟合：正样本 16,774 个，负样本 16,644 个。
- **三个人群：** 训练图的另外三分之一（B，检测器训练时见过、探针没见过）和 val（两者都没见过），各自再按与训练集的相似度 sim 分档。
- **指标：** 在 val 负样本上误报率为 1%（另报 0.1%）的阈值下，各人群正样本的召回率。
- **读法（运行前写在工具里）：** 对 sim < .9 的目标，探针在训练图 B 上明显高于 val，说明落差已经在特征里；两者相当，说明落差出在 encoder 之后。
- 代码 `tools/sardet100k/generalisation_probe.py`。服务器输出 `independent_verify_20261106/d12_probe/`，本地 `analysis_outputs/d12_probe/`。GPU 0、1。

### 判读

1. **落差已经在特征里，不是检测头造成的。**
   - 512 / aircraft 最清楚：encoder 特征上，一个新训练的线性探针对有副本的 aircraft 召回 100%，对没有副本的只有 79.2%；检测器最终是 99.8% 对 80.0%。两者几乎相同，解码器和检测头没有再丢更多。
   - backbone 输出上这个差距就已经存在（86.0 对 62.2）。
   - 在更严的误报率（0.1%）下，各单元格 encoder 特征上的“有副本 − 没有副本”差距为 aircraft 38、tank 18、bridge 10、ship 3–4，与检测器的差距（20、20、15、3–7）次序相同、量级相当。
2. **特征层面存在记忆，但在大多数单元格里幅度不大。** 同一单元格内，没有副本的目标在训练图 B 上都比在 val 上更可分：ship、car 相差 0.4–2.0 点，bridge 2–4 点，小 tank 7.5–9 点。按运行前写定的读法，这属于“训练图 B 高于 val”，即落差在表征里。
3. **去掉 Dense O2O 之后，没有副本的 aircraft 在 encoder 特征上更难分了**（79.2 → 73.1 → 64.7），与它们的 AP 下降（32.5 → 27.3 → 27.5）方向一致。混合增强改善的是特征，不只是检测头的置信度。
4. **像素本身没有这个差距。** IMG 在训练图 B 与 val 上几乎一样（32.6 / 32.0），说明差距是学出来的特征造成的，不是两批图像在像素统计上的不同。
5. **检测器自己的 encoder 读出（ENC_SCORE）并不比新探针强。** 它在 bridge、800 ship 上明显低于探针，这部分差别来自它的训练目标（一对一、按 IoU 给分），不能直接解读为头部的缺陷。

### 对主线的含义

- **主线模块应当作用在特征上（backbone 或 encoder），而不是 query、匹配或分数。** 以“query 质量”为名的头部改进，改变不了没有副本的目标在特征上就分不开这件事。这与分数侧六项检验全部为负是一致的。
- **目标可以写得很具体：** 让没有副本的目标在 encoder 特征上更可分。现在有了一个不需要训练完整检测器就能读的机制指标：本节的探针召回率，尤其是 512 / aircraft 的 79.2%。
- **已知有效的杠杆只有一个：** 训练时的混合增强（对大目标）。SAR 预训练骨干在文献里的增益（约 +5 AP）也指向表征。
- **最弱的单元格是 512 / aircraft。** 它的损失全部在表征上；小 tank 和 bridge 还叠加了图像证据不足。

### 局限

- 探针是线性的、类别无关的，只用 8,000 张训练图拟合，负样本是随机框，不是检测器真正面对的强杂波。
- 特征按 GT 框池化，等于给了探针真实位置，所以探针召回率不能与检测器召回率直接比大小；能比的是“有副本 − 没有副本”的差距。
- 512 / aircraft 在训练集里几乎没有“没有副本”的样本，无法用训练图 B 作对照来排除“这些目标本身不典型”。它的结论依据是特征差距与检测器差距相同，以及 D12 中其他单元格的训练图对照。
- 单种子、单个检查点；探针本身没有重复。

## D12.3 相对周边杂波的特征是否让没有副本的目标更可分（2026-11-11）

### 口径

- 与 D12.2 相同的框、训练图 A / B 划分、线性探针和阈值（负样本也相同）。对 backbone（BB）和 encoder（ENC）的 stride 8 / 16 / 32 输出，比较五种池化特征：

| 变体 | 内容 |
|---|---|
| inside | 框内 3×3 采样的平均（D12.2 的参照） |
| diff | inside − 环形区域均值：减去局部杂波 |
| cfar | (inside − 环形均值) / (环形标准差 + ε)，逐通道：按局部杂波归一化 |
| scene | (inside − 整图均值) / (整图标准差 + ε)，逐通道：按场景归一化 |
| inside+ring | inside 与环形均值拼接（对照：探针可以自己组合出任何差） |

- 环形区域取 1.5 倍和 2 倍框上各 8 个点（四角和四边中点）。
- **像素级 CFAR 对比度（不经任何学习）：** 640 输入上 (框内均值 − 环形均值) / 环形标准差。用来回答 D12.2 留下的对照问题：没有副本的目标是不是本身就更弱。
- **读法（运行前写在工具里）：** diff、cfar、scene 中任一个，在同样误报率下让 512 图 aircraft 中没有副本的目标召回率高于 inside ≥ 3 点（1% 误报率）或 ≥ 5 点（0.1%），三次运行同号，且不降低有副本目标的召回率，才算支持“特征层杂波归一化”。
- 代码 `tools/sardet100k/clutter_relative_probe.py`（extract / analyse / matched）。服务器输出 `independent_verify_20261106/d12_clutter/`，本地 `analysis_outputs/d12_clutter/`。GPU 0、1。

### 判定

按运行前写定的读法，**特征层杂波归一化没有得到支持：**

- 对 512 图的 aircraft，三种归一化在三次运行里都是正的，但 1% 误报率下只有部分达到 3 点（diff +2.3 / +1.5 / +9.3，cfar +3.0 / +1.9 / +8.9，scene +2.4 / +3.5 / +9.5）。在 0.1% 误报率下 diff 与 cfar 达到了（+8 到 +14）。
- 但它们降低了有副本目标的召回率（encoder 上 −0.4 到 −1.7 点），全体没有副本的目标也下降，小 tank 大幅下降（90.7 → 69.6）。小目标的环形采样点在 stride 8 以上的特征图上与目标落在同一两个格子里，减去它等于减掉目标自己。
- 在 backbone 上归一化全面变差。

### 判读

1. **“减去杂波”不对，“加上周边”有用。** 作为对照放进去的 inside+ring 反而是唯一一致为正的：backbone 上全体没有副本的目标 +3.8 到 +3.9 点，512 aircraft +7 到 +11.5 点，小 tank +6 到 +8 点；encoder 上幅度小（全体 +0.3 到 +1.7，0.1% 误报率下 512 aircraft +5 到 +8），没有一个单元格下降。周边区域带有可迁移的证据，网络需要的是用它，而不是把它归一化掉。
2. **这是线索，不是结论。** encoder 本身已经在聚合上下文，所以它上面的增量小；此前的 GREA 把保护环证据加在解码器最后两层，训练结果是 −0.92。冻结特征上探针变好，不等于训练后的检测器变好。
3. **没有副本的目标确实平均更弱。** 512 aircraft 的像素对比度中位数是 0.24 对 0.81。D12.2 留下的这个疑问成立。
4. **但弱不是原因，记不记得住才是。** 把对比度配对之后，最弱的一档（对比度低于周边）里，有副本的 aircraft 无论在训练图还是 val 上召回都是约 100%，没有副本的只有 45%。同样弱的目标，网络“认识”的就能检出，不认识的就检不出。对比度高的一档，没有副本的也有 95–98%。
5. **所以损失集中在“既没有副本、对比度又低”的目标上。** 对这些目标，网络现在靠的不是图像证据而是记忆；512 aircraft 里最弱的那四分之一（约 318 个）可能本身就没有足够的可用证据，这部分是上限问题。

### 对主线的更新

- 问题来源比 D12 更具体：**低对比度目标的检出依赖记忆。** 有副本时网络记得住（约 100%），没有副本时只能靠证据，而对比度低时证据不够（45–88%）。
- 不支持的方向：特征层的杂波归一化（CFAR 式）。
- 有线索的方向：显式使用目标周边的特征。它与 GREA 的想法相近，而 GREA 加在头部已经失败，所以如果要做，必须放在特征层（encoder 之前或之内），并且先说清它与 GREA 的区别。
- 已被数据支持的杠杆仍然只有训练时的混合增强：它让没有副本的 aircraft 在 encoder 特征上更可分（79.2 对 73.1 / 64.7），AP 高 5 点。

### 局限

- 特征是在没有这类归一化的情况下训练出来的，事后归一化只是弱代理；负结果不排除训练出来的模块有效。
- 探针是线性的，负样本是随机框；环形区域只取 16 个点。
- 配对对照只用了 encoder 的 inside 探针，没有用检测器本身的检出结果。
- 单种子；E009 的配对对照没有跑。

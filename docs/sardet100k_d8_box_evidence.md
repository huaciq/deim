# D8 定位质量的图像证据：同一 GT 的好框与差框

接 [D7.2–D7.3](sardet100k_d72_d73_joint_probe_swap.md)。那一轮的结论是：同一目标的 IoU ≥ .5 候选内部重排有 +4.74 AP 的上限，但分类分数和 box head 隐层都读不出“哪个框更准”。这一轮问：**这个信息在图像里、或在更早的多尺度网络特征里有没有？**

不训练、不改结构，只用 CPU。权重为 E000 第 35 轮 EMA（`best_stg2`），val。

## 控制

每次比较都是**同一个 GT 的两个候选**：同一张图、同一个目标、同一类别。场景、类别、目标身份都不同的情况不进入比较，所以差异只能来自两个框的位置和大小。

- **候选：** 与 D7 相同。同类 GT 中以该 GT 为最大 IoU 对象、且 IoU ≥ .5 的末层 query；至少两个候选的 GT 才参与。
- **框几何对照：** 两个候选的位置、大小本来就不同，所以每个特征族都要在框几何（S0）和现有分数（S1）之外检验增益。
- **特征不使用 GT。** 只用预测框和图像（或同一次前向的网络特征），原则上可以部署。

## D8.1 好框与差框的对照

- **主比较对：** 同一 GT 中“最佳框”（IoU 最高）与“最高分框”不同且 IoU 相差 ≥ .1 的情况。这正是分数选错、损失 AP 的那一类。另外报告全部竞争对（与 D7 相同的定义）。
- **可读的描述量**（每个候选一个数）：

| 描述量 | 含义 |
|---|---|
| interior_mean / interior_max | 框内平均、最大强度 |
| centroid_offset | 框内“高于背景”部分的质心偏离框中心的距离（框边长为单位） |
| edge_contrast | 四条边内侧带减外侧带的平均强度差 |
| energy_capture | 2 倍框区域内高于背景的能量落在框内的比例 |
| ring_mean / ring_std | 1.5–3 倍框环形背景的均值、标准差 |
| ring_max_minus_interior_max | 背景最亮点减框内最亮点（> 0 表示背景里有比目标更亮的散射） |
| ring_bright_share | 背景采样中比框内均值更亮的比例 |
| net_{s4,p3,p4,p5}_inside_share | 该尺度特征范数在框内的均值除以框外（2 倍框内）的均值 |

  每个描述量报告“好框 − 差框”的中位数，以及好框更高的比例（按图像 bootstrap 的 95% CI）。
- **对照图：** 每行一个 GT，6 列依次为原图裁片（黄 = GT，绿 = 最佳框，红 = 最高分框，橙 = IoU < .5 中分数最高的候选）、拉伸对比度的裁片、backbone stride 4 和 encoder stride 8/16/32 的特征范数图。OGSOD tank 8 例、OGSOD bridge 6 例、other_512 aircraft 6 例、other_256 ship 4 例，从 IoU 差最大的前 4k 个中按固定种子抽取。

## D8.2 四组独立特征探针

| 探针 | 来源 | 内容 | 维度 |
|---|---|---|---:|
| P1 框内散射结构 | 原图 | 框内 7×7 双线性采样；均值、标准差、最大值；亮部质心相对框中心的偏移 | 54 |
| P2 框边界 | 原图 | 每条边的横跨剖面（−.25 … +.25 框长，正为框内，沿边平均）；每条边内外对比；能量落在框内的比例 | 25 |
| P3 周边背景 | 原图 | 1.5–3 倍框环形区域：均值、标准差、中位数、q90、最大值；四侧均值；与框内的最大、均值差；更亮比例 | 12 |
| P4 多尺度网络特征 | 同一次前向 | 每个尺度：框内 3×3 采样的平均特征 + 2 倍框区域 5×5 的特征范数分布（除以均值）。尺度为 backbone stage 1（stride 4，96 通道）与 encoder 的 3 个输出（stride 8/16/32，256 通道） | 964（各尺度 121 / 281 / 281 / 281） |

- 原图为 8 位灰度、原始分辨率、除以 255；网络特征取 640 输入的那次前向。
- 采样都以框为坐标系（框的左上为 0、右下为 1），所以特征本身就随框的位置变化。
- 每组先单独测，不融合。P4 另外按单个尺度分别测，看各尺度是否给出一致的证据。

### 评价（沿用 D7 体系）

| 指标 | 回答什么 |
|---|---|
| 同一 GT 内的两两排序正确率（GT 加权，图像分组 5 折，折外） | 这组特征能否分出更准的框 |
| 与真实 IoU 的 Spearman（每个 GT 内） | 同上，连续版本 |
| (S0 + Pk) − S0 | 在框几何之外有没有信息 |
| (S0 + S1 + Pk) − (S0 + S1)，配对图像 bootstrap | 在几何和现有分数之外有没有**新**信息 |
| 全 val AP 交换：用 S0 + S1 + Pk 的折外得分在同一 GT 的候选内重排 logit | 这部分信息值多少 AP |

排序器、折、权重、L2 搜索、bootstrap 与 D7.1–D7.3 完全相同。交换规则与 D7.3 相同：只在同一 GT 的候选之间重排已有的 logit，框和其他检测不动。

### 判定（先于结果写定，2026-11-10）

| 结果 | 结论 |
|---|---|
| 某个 Pk 的交换使全 val AP 提高 ≥ 0.5，且明显高于 S0 + S1 对照 | 这一族证据值得做成模块，下一步写实验卡（只针对这一族的机制） |
| 某个 Pk 在几何与分数之外有显著增益（区间不含 0），但交换 < 0.5 | 证据存在但不够，记为线索，不训练 |
| 四族都 < 0.5，且条件增益都不显著 | 这些手工和多尺度特征里也没有足够的质量信息；IoU ≥ .5 候选内的排序不作为下一步方向 |
| S1 final 的交换不复现基线 | 工具有错，结果作废 |

另外按单元格记录，看收益是否只来自一个来源。

局限（预先写明）：

- 线性排序器是下界，P1–P3 是手工特征，只覆盖了几种直观的图像结构。
- P4 只取了 4 个尺度，每个尺度只做了框内平均和范数分布，没有保留完整的空间特征。
- 交换实验是 GT-aware 的上限：候选集合由 GT 决定，排序器用 GT 的 IoU 训练。

## 结果（2026-11-10）

**检查：** 20,097 个有至少两个候选的 GT（与 D7.3 的 20,101 差 4 个，来自 CPU 前向在 Top-300 边界上的差异）。S1 final 交换复现基线：65.30 / 93.16 / 70.29。本地副本在 `analysis_outputs/d8/`。

对照图 `analysis_outputs/d8/d81_gallery.png`（24 例）。读法：

1. **aircraft 和 ship：分数偏爱过紧的框。** 最高分框只框住最亮的散射点，好框还包住了较弱的部分：好框内平均更亮（aircraft .71），框外留下的亮点更少（ring_bright_share .33、.26），stride 4 特征更集中在框内（aircraft .70）。图中 aircraft 的红框常落在机身亮点上，绿框才包住机翼的弱散射。
2. **OGSOD tank 正好相反：分数偏爱包住最亮像素的框，而更准的框常常不包含它**（interior_max 只有 .25 的情况好框更亮）。在图中，tank 的目标在斑点背景里几乎看不出来，单个亮像素不代表目标的范围。
3. **OGSOD bridge 没有一个描述量能区分**（.41–.50）。
4. **好框的分数很多接近 0。** 图中大多数例子里好框 s ≤ .1，它是被一对一压制下去的重复候选。这一类损失不是“分数略低”，而是“选中了另一个”。

这些差异是真实的，但它们与框的大小、位置高度相关；它们在几何和现有分数之外是否带来新信息，看 D8.2。

### 判定

按先前写定的表：**四组交换都没有提高全 val AP**（最高 −0.05），条件增益只有 P4 在 OGSOD tank 和 aircraft 上显著，且换不成 AP。归入第三行：**这些手工图像特征和多尺度网络特征里也没有足够的质量信息；“IoU ≥ .5 候选内部的排序”不再作为下一步方向。**

### 判读

1. **图像里的差异真实存在，但分数已经用到了。** aircraft、ship 的“分数偏爱过紧的框”在 D8.1 里很明显，可一旦控制几何和分数，P1–P3 没有新增信息。分数选错的那部分 GT，它们的图像证据与选对的 GT 看起来一样。
2. **多尺度网络特征带有大量几何之外的质量信息，但几乎全部已经进入了分类分数。** 单独看 P4 都低于 S1（例如 MSAR tank .847 对 .953）。唯一的例外仍是 OGSOD tank，这与 D7.2 一致，而这一格只占 GT 的 5%。
3. **OGSOD tank 的目标在图像上几乎不可分辨。** 在对照图中，8 px 的 tank 淹没在斑点里，更准的框常常不包含最亮的像素。可以断言的是：现有图像强度结构里没有能稳定指示 tank 框范围的信号。
4. **剩下的 +4.7 AP 上限对应的是“选中了哪个候选”，而不是“分数差一点”。** D8.1 里好框的分数大多接近 0，属于被一对一压制的重复候选。这一点与 E004 一致：把好框选成正样本，重复抑制就失效。

### 局限

- 线性排序器，手工特征只覆盖了几种直观的结构；P4 只取了框内平均和范数分布。非线性或更细的空间读出不能排除。
- 交换是 GT-aware 的上限，而 P4 交换的下降主要是高维排序器的折外噪声，不等于 P4 有害。
- 单种子、单个检查点；D8.1 的“分数选错”样本在 MSAR 上几乎没有。

# BCLQ（框条件定位质量分支）方案评审与零训练检验（D10）

日期：2026-11-10。对象：用户提出的 BCLQ 方案。按预测框从 neck 特征取框内与周边特征，与 query 特征融合，预测每个 query、每个类别的定位质量 Q̂，用全部 query 的 IoU 作监督，推理时 `z_final = z_cls + β·logit(Q̂)`。

这份文档回答三件事：方向是否可行；应当怎样改；会不会损害别的地方。结论先放在前面。

## 结论

1. **方向有条件可行，但它能起作用的地方与方案的出发点不同。** 加法融合在 β ≤ 1 时有效，这时它几乎不改变同一目标内谁排第一，收益来自给不同目标的检测框按定位质量重新排序、压低不合格框。方案想解决的“把被压低的好框救回来”需要大的 β，而大的 β 会让重复框失控。
2. **成败取决于一个还没测过的量：** 质量头能否给出与分类分数**误差不相关**的 IoU 估计。已有的探针（D7、D8）只测了同一目标内的两两排序，结论是没有新信息；跨目标的绝对质量没有测过。
3. **下一步不是直接训练，而是一个冻结特征的零训练检验（D10.2）：** 用现有特征拟合 IoU，按加法融合换算成全 val AP。过了门槛再实现 BCLQ 并训练。
4. **D10.2 已完成（2026-11-11），没有通过：** 用真实特征拟合的质量头，融合后全 val AP 比不融合低 1.1（β = 1），最好的输入组合只比“分类分数 + 几何”的对照高 0.06。按事先写定的判定，**BCLQ 不实现、不训练。** 详见文末。

## 零训练检验（D10.1）：模拟一个质量头

- **做法：** 质量头用真值加噪声模拟。Q = clip(t + ε, .02, .98)，t 是 BCLQ 的训练目标（该 query 的框与图中 c 类 GT 的最大 IoU），ε ~ N(0, σ²)，对每个 query、每个类别独立。σ = 0 是完美的头。
- **两种融合：**
  - `add`：`z_cls + β·logit(Q)`，即方案的写法。
  - `swap`：不使用 GT 把 query 分组（按 z_cls 排序，未分组的第一个作种子，与它 IoU ≥ .5 的未分组 query 归入同组），组内按 Q 的顺序重新分配已有的 z_cls。分数的集合不变，所以一对一去重按构造保持不变。
- **数据：** E000 第 35 轮，全 val，D8 那次 CPU 前向的 `queries.npz`。基线 65.30 / 93.16 / 70.29。
- **读法在运行前写进了工具的文档串：** add 要在可达到的精度下有某个 β 使 AP ≥ +0.5 且 AP50 降幅 ≤ 0.5；swap 看 AP 达到 +0.5 所需的两两排序正确率，并与分类分数的正确率比较。
- **重要限制：** 模拟头的误差与分类分数的误差**相互独立**。真实的头看到的是骗过分类器的同一批特征，误差会相关，所以这里的数字是乐观的上界，只用来判断融合方式和所需精度。
- 代码 `tools/sardet100k/quality_fusion_oracle.py`；服务器输出 `independent_verify_20261106/d10_quality_fusion/`（git `6e305c3`），本地 `analysis_outputs/d10_quality_fusion/`。没有做 bootstrap。

### 加法融合（方案的写法）

| 头的精度 | 同目标两两正确率 | β = 0.5 | β = 1 | β = 2 | β = 4 | β = 8 |
|---|---:|---|---|---|---|---|
| σ = 0（完美） | 1.00 | 69.84 / 95.63 | **71.04 / 95.76** | 70.94 / 93.54 | 65.96 / 83.37 | 58.02 / 70.72 |
| σ = .1 | .78 | 68.80 / 95.51 | **69.35 / 95.43** | 67.67 / 90.85 | 59.44 / 77.19 | 53.23 / 68.28 |
| σ = .2 | .69 | **67.58 / 95.23** | 67.42 / 94.66 | 64.03 / 87.93 | 54.61 / 74.45 | 50.30 / 68.87 |

每格为 AP / AP50。排在本类中位 TP 之前的重复框数：基线 3；σ = .1 时 β = 1 为 10，β = 2 为 303，β = 4 为 2,863，β = 8 为 5,464。

1. **β ≤ 1 时有效且不伤 AP50。** 完美的头 +5.7 AP；σ = .2 的头也有 +2.3 AP、AP50 +2.1。
2. **β ≥ 2 时重复框失控，连完美的头也一样。** 完美的头在 β = 4 时 AP50 掉 9.8，β = 8 时掉 22.4。原因是 Q 的目标按定义是一对多的：同一目标附近的每个 query 都得到高 Q，这正是一对一分类要压掉的东西。这与 E004 是同一种失败。
3. **小 β 的收益不来自“同一目标内选对框”。** σ = .2 的头在同一目标内的两两正确率只有 .69，低于分类分数自己的 .81，AP 仍然 +2.3。收益来自跨目标：IoU 高的框排到 IoU 低的框前面，不合格的框被压低。
4. **所以方案 2.4 节的设想不成立：** “原分类分数 .02、质量很高的候选应当重新进入有效排序”需要补上约 4 个 logit 的差距（D9：OGSOD 错误锁定对的 logit 差中位 4.26），而 IoU .68 与 .83 的 logit(Q) 只差约 .8，要 β ≈ 5。这个 β 已经在重复框失控的区间里。

1. **交换能在不伤去重的前提下拿到“同一目标内选对框”的全部空间**（+4.95，与 D7.3 的上限一致），AP50 不降。
2. **盈亏点在分类分数自己的正确率附近（.80）。** 头的两两正确率要高于分类分数约 .02–.03 才有 +0.5 AP。
3. **已有探针都没有达到这一点。** D7.3、D8 中 box head、图像结构、多尺度特征的线性读出，在 GT 数 300 以上的单元格里与分类分数相差都在 ±.005 以内（OGSOD tank 除外）。
4. **用质量头整体替换组内顺序会伤害原本排得好的单元格。** σ = .08 时全局 +1.1，但 MSAR tank −3.4、MSAR ship −2.9；OGSOD tank +7.0。因为 MSAR 上分类分数的正确率是 .93–.95，一个 .82–.86 的头在那里是倒退。

## 对方案各环节的判断

| 环节 | 判断 | 依据 |
|---|---|---|
| 从预测框取框内、周边特征 | 可以做，但不要预期它在同一目标内分出好坏 | D8 的 P4 就是这类特征的冻结线性版本：在几何与分数之外的增益为 0，只有 OGSOD tank +.047、aircraft +.009 |
| OGSOD tank 上的框内 / 环形对比 | 预期最弱 | 8 px 的 tank 在 640 输入上约 20 px，stride 8 上只有 2.5 格，1.5 倍框的环只多出约 1 格；D8.1 里 tank 的图像描述量没有一个能区分好框 |
| aircraft、ship 上的“框是否过紧” | 最有可能学到 | D8.1：好框框外残留的亮点更少（.33、.26），stride 4 特征更集中在框内（.70） |
| 全部 query 参与的 IoU 监督 | 合理，也是它与 LQE 的真正区别 | LQE 没有独立监督，MAL 对未匹配 query 的目标恒为 0，网络从未被要求知道落选框的质量。这一点现有探针无法否定 |
| 6 个类别各一个质量值 | 不建议 | 质量是框与目标的几何关系。按类别输出等于再建一个一对多的分类器，参数更多，而且把一对多的类别信号加进分数正是重复框的来源 |
| `q' = q + gate·h` 改写 query 特征 | 不建议 | 它会改变分类头的输入，让一对多的质量信号进入一对一的分类训练，风险与 E004 相同 |
| 加法融合，β 可调 | 只在 β ≤ 1 可用 | 见上表 |

## 建议的改造（BCLQ-v2）

1. **质量头独立，不改写 query 特征。** 输入为 detach 的 query 特征、detach 的预测框，以及按框取的特征；输出不回到分类头和 box head。第一版对原模型的输出逐位不变，只多一个分支，便于确认没有副作用。
2. **输出 1 个类别无关的质量值**（与任意 GT 的最大 IoU）。类别由分类分数给，推理时加到全部 6 个类别的 logit 上。
3. **监督用质量焦点损失（BCE + 软目标），不用 SmoothL1。** 300 个 query 里多数 IoU 为 0，回归损失会被负样本淹没。负样本降权，IoU ≥ .1 的 query 全权重。
4. **融合只在推理时做，β 固定为 1，不学习、不进入匹配和 MAL。** 进入训练就会改变一对一的分配；可学习的 β 没有任何东西阻止它走进重复框失控的区间。
5. **取特征的层和采样方式：** stride 8 与 16 两层。框内用 3×3 采样（不是平均池化，保留位置）；环形区域取 1.5–2 倍框。小于 16 px 的框在 stride 8 上分辨不出内外，不要指望它对 OGSOD tank 起作用。
6. **新增参数估计：** 两层各一个 1×1 降维（256 → 64）加一个 3 层 MLP，约 0.2 M，占 19.5 M 的 1%。

## 可能的损害

| 风险 | 何时出现 | 怎么避免或发现 |
|---|---|---|
| 重复框增加、AP50 下降 | β ≥ 2，或质量信号进入分类训练 | β 固定为 1；检查分数 ≥ .3 的重复框数（E000 为 379） |
| 原本排序好的来源变差（MSAR） | 用质量头替换组内顺序 | 用加法而不是替换；单独看 MSAR 两格的 AP |
| 训练被拖慢或互相干扰 | 质量头的梯度进入共享特征 | 第一版全部 detach；之后再放开作消融 |
| 质量头只是复述分类分数 | 特征里没有独立的质量信息 | D10.2 在训练前就能发现 |
| 速度 | 300 个 query × 2 层的采样 | 开销很小，但要报告 FPS |

## 新颖性（需核实）

- “在预测框上取特征估计 IoU、用它校准分数”是 IoU-Net 的做法。
- DETR 上有很接近的工作：Cascade-DETR（ICCV 2023）用框约束的注意力，并有 IoU-aware query recalibration。这是凭记忆写的，动手前要读原文确认差别。
- DEIM 的 MAL、D-FINE 的 VFL 已经在损失里做 IoU 感知。
- 所以 BCLQ 本身不能作为主要创新点。能写的是 SAR 上的诊断（一对一锁定由外观偏好决定、与框质量无关）加上一个据此设计的模块；“框内 / 环形散射对比”这个 SAR 角度目前没有数据支持（D8 的 P1–P3 条件增益为 0）。

## 下一步：D10.2（零训练，CPU）

**问题：** 现有特征能否给出比分类分数更多的**绝对**定位质量信息？这是 BCLQ 在 β ≤ 1 区间里起作用的前提，也是唯一没有测过的一环。

- 对每张 val 图分数 ≥ .02 的全部 query（含背景和不合格框，不只是 IoU ≥ .5 的候选）提取：分类 logit、框几何、box head 隐层、按框取的多尺度特征（D8 的 P4，加 3×3 不平均的版本）。
- 按图像分组 5 折，拟合 IoU（先线性，再一个小 MLP）。
- 用折外预测 Q̂ 做 `z_cls + 1·logit(Q̂)`，算全 val AP。
- **对照：** 只用分类 logit 和几何拟合的 Q̂。它量的是“重新标定”本身的收益，必须扣掉。
- **判定（现在写定）：** 含框条件特征的 Q̂ 比对照高 ≥ +0.5 AP，且 AP50 不降超过 0.5，就实现 BCLQ-v2 并训练一次；否则不训练，记为“特征里没有独立的质量信息”。
- 冻结特征是下界：端到端训练可能学出更多。但如果冻结特征连 +0.2 都没有，一次 18 小时训练的先验就很弱。

## D10.2 结果（2026-11-11）：没有通过

### 口径

- **样本：** 最高类别分数 ≥ .02 的全部 query（TP、重复框、定位不足的框和背景框）。val 全部 10,492 张图共 129,940 个；训练集按种子 0 随机取 12,000 张图，共 108,535 个。同一检查点（E000 第 35 轮 EMA）的一次 CPU 前向。

### 判定

按事先写定的规则：最好的一组比对照高 +0.06（区间含 0），远低于 +0.5；而且所有输入组合在 β = 1 时都比不融合低 1.1–1.4 AP、AP50 低 1.8–2.7。**不实现、不训练 BCLQ。**

### 判读

1. **质量头确实学会了预测 IoU**（MAE .05，Spearman 从 .74 升到 .80），**但这个预测融合进分数后只有害处。** 原因是它预测对的那部分，分类分数已经有了：DEIM 的 MAL 用 IoU^1.5 作分类目标，分类分数本身就是一个按定位质量训练出来的分数。再加一个估计同一件事的量，带来的是重复计数和噪声，不是新信息。D10.1 的模拟之所以有 +2 到 +6 AP，完全来自“误差与分类分数独立”这个假设；真实特征不满足它。
2. **损害来自跨来源、跨尺寸的重新排序。** 各单元格内部的下降不大（OGSOD tank −0.6、MSAR tank −0.2），但 tank 整类掉 1.3。预测的 IoU 与目标尺寸、来源强相关（小目标的 IoU 天然低），把它加到分数上等于系统性地把小目标和难来源往后排，而类别 AP 是把所有来源放在一起排的。这与 E003 的教训是同一件事的两面。
3. **按框取的特征没有带来帮助，反而略差。** BOX 比只用 query 特征的 Q 低 0.2 AP（区间不含 0）。同一 GT 内的两两正确率只从 .615 到 .630。
4. **val 内拟合再次高估了 aircraft。** val 5 折下 other_512 aircraft +1.5 AP，训练图拟合只有 +0.4 到 +0.5，其余单元格两种口径一致。这正是 BAFR 记录过的现象，也说明主口径选训练图拟合是对的。
5. **冻结特征是下界，这一点仍然成立**：端到端训练可能让特征学出别的东西。但那需要让质量损失的梯度进入共享特征，也就是放弃“不改写 query 特征、不影响分类”这个安全设计，回到 E004 的风险上；目前没有任何数据支持这样做会有收益。

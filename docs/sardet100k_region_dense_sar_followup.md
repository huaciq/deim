# RegionDense 后续方向：背景相容的保尺度密集训练

日期：2026-11-11。本文保留设计诊断时的记录：完成训练集 CPU 诊断及组图规划原型，没有 v2 AP。参考代码版本：`9ce143f`。后续已按用户指令实现，正式协议与启动/恢复命令见 [RegionDenseSAR 实验](sardet100k_region_dense_sar_experiment.md)。

## 为什么值得继续

E009 相对同服务器 E008：val AP +0.26、test AP +0.11、test AP75 +0.46、test APs +0.96，但 test APl -3.10。这支持将 RegionDense 保留为辅助模块候选。原定 +0.5 是首轮资源筛选线，不是辅助贡献必须遵守的统一门槛；原实验未通过该筛选线的记录仍然保留。

下一版集中解决两个相连的问题：可裁区域的抽样偏差，以及不同背景直接拼接的突变。目标是继续增加有效正样本，同时保持目标尺寸分布和局部背景关系。

## 新发现：类别平衡不等于尺寸平衡

本轮读取全部 94,493 张训练图的标注和 v1 区域库，按实际“类别桶→源图→裁块”的概率计算新增 GT 的期望。只分析训练数据，没有重新推理，也没有用 AP 选择参数。

按原图标注面积分组，启用增强的 16 轮内：

| 分组 | 相对普通输入的目标出现次数 | 普通输入中的占比 | v1 增强阶段占比 |
|---|---:|---:|---:|
| 小，面积 < 32² | 1.614 倍 | 60.70% | 64.15% |
| 中，32² ≤ 面积 < 96² | 1.445 倍 | 33.86% | 32.02% |
| 大，面积 ≥ 96² | 1.073 倍 | 5.45% | 3.83% |

因此，大目标绝对次数没有减少，但相对占比被稀释。按普通 640 缩放后的框面积重算也有同方向偏差：大目标占比从 20.43% 降至 15.41%。它是可修正的数据偏差，尚不是 APl 下降的因果证明，也不是实际梯度测量。

统计为排除重复源图、超过 300 GT 回退之前的静态期望；面积分组使用互斥边界，不冒充 COCO evaluator 的完整分组行为。v1 增强阶段期望为 3.211 GT/输入；此前 10,000 次抽样的 3.269 属于有限抽样估计。

## 推荐方案：同一批原图，改变组合方式

### 1. 按原图顺序取用，保持目标出现比例

把训练原图打乱，放入一个有限等待队列。每次取最早进入队列的图作为主图；若它的全部目标和受保护邻域能装入半图或四分之一图，则尝试从队列中找其他合适的原图共同组图。用于补入的图也必须保留其全部 GT 和邻域。

每使用一张源图就从队列移除。放不进小块的图正常以整图训练。这样，每完成一遍源图，每张原图、每个 GT 都恰好用过一次；类别、尺寸和实例频率都保留。无需再对可裁区域进行独立重复抽样。

保持每轮输出画布数量、global batch 和优化器步数与基线一致；增强阶段可以更快遍历源图，再继续下一遍。这里的“一遍源图”与“一个训练 epoch”是不同概念。完整源图遍历的比例严格保持；训练阶段结束时尚未完成的那一遍仍有有限抽样波动。

全训练集 CPU 几何规划（队列 64、尝试概率 0.5、seed 20261111）：

| 项目 | 结果 |
|---|---:|
| 使用源图 / 不重复源图 | 94,493 / 94,493 |
| 保留 GT / 原始 GT | 198,676 / 198,676 |
| 输出画布 | 63,976 |
| 平均 GT/普通输入 → GT/规划输入 | 2.103 → 3.105 |
| 固定画布预算下的源图遍历倍率 | 1.477 |

以上仅为几何规划，尚未加入背景选择。保持目标次数也不等于保证训练梯度或 AP 一定改善。

### 2. 根据 SAR 背景的可观察差异选择组合

保留目标和原有邻域，优先将亮度、对比度、局部颗粒纹理相近的区域放到同一画布中。例如，避免将平滑暗背景与高亮密集杂波直接拼接。背景选择只改变本批原图的组合和顺序，不删除“不相似”的源图。

当前 CPU 原型：在合法裁块中遮去 GT 框及框外 2 px，提取背景灰度的 25/50/75 分位数，以及相邻像素灰度差的 50/90 分位数。按训练样本的特征四分位距归一化，计算平均绝对差；从队列中几何合格且最接近的最多 4 张源图中随机选取。没有类别筛选，没有修改像素亮度，也没有去斑处理。特征不足时允许普通随机选择。

这些是 JPEG 显示图像的统计代理，不能称为定标后向散射、真实斑点参数或 ENL。数据标注没有传感器、入射角、GSD、极化等字段，因此当前设计不依赖这些元数据。现有固定邻域也不能声称完整覆盖所有 SAR 阴影。

SAR 目标与周边散射环境、杂波的关系具有研究依据；但已有 SAR ATR 文献只能支持动机，不能替代本检测方法的效果验证。参考：[Geng 等，2023，Target Recognition in SAR Images by Deep Learning with Training Data Augmentation](https://www.mdpi.com/1424-8220/23/2/941)。SARDet-100K 的多来源背景见[数据集论文](https://arxiv.org/abs/2403.06534)。

### 3. 已完成的真实图像 CPU 检查

固定抽取 2,048 张 train 图、3,964 个 GT。两种组图规划均将每张源图和其全部 GT 使用一次；合法裁块取可用原点区间的中点，沿用 v1 邻域几何规则。

| 项目 | 队列内随机组图 | 队列内按背景相容性组图 |
|---|---:|---:|
| 平均 GT/画布 | 2.932 | 2.848 |
| 缝两侧平均灰度差，0–255 | 59.65 | 24.69 |
| 保留 GT | 3,964 | 3,964 |
| 每张源图恰好一次 | 是 | 是 |

这一子集普通输入为 1.936 GT/图。相容选择后，目标密度仍提高约 47%；相对随机队列组图，密度约降低 2.9%，缝两侧灰度差约降低 58.6%。

灰度差测量为接缝两边各 8 px 宽的背景条带，在对齐的 16 px 长度内分别取中位数，再汇总绝对差。这里只说明所设计的选择规则能够减少该种背景突变，并保留密集目标；不是 AP 证据，也不能与全训练集几何规划的 3.105 混为同一统计。

## 下一步只做一版完整训练候选

将上述源图规划和背景选择一起接入独立 v2 配置，保留 v1 的普通全图路径、目标尺度、受保护邻域、启用轮次和尝试概率。模型、匹配、MAL、损失、初始化、学习率、batch、EMA、AMP、36 轮与评估协议继续使用 E008/E009 的设置。

正式实现时需要在主进程统一生成确定性组图计划，再分发给 DDP ranks 和数据工作进程；不能让每个 worker 各自维护一个互不关联的源图队列。恢复训练也必须能恢复计划位置。完整训练前只验证具体功能：实际裁块和坐标正确、全部可见 GT 保留、跨 rank 的源图计数、输出步数及恢复位置。

下一次先进行一组完整 v2 训练，以 val 选择 checkpoint，观察总体 AP、小目标收益及大目标退化是否改善，再做固定 test 报告。不围绕队列大小、边距和概率展开一串训练调参。最终论文若将其作为辅助贡献，再在确定的主要方法上补有/无该模块的组合消融。

背景约束与频率修正构成当前推荐设计。新颖性仍须与区域选择式 Mosaic 等相关工作比较，不能仅凭名称或简单拼图规则声称首次提出。

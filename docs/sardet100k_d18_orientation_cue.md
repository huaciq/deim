# D18 上下不对称是不是有用的线索（E013 的训练前检验）

> 2026-11-12 代码复核更正：A 的旧实现比较像素总和，奇数框下半/右半面积更大，存在系统偏差；
> 已改为均值并增加提取版本字段，下面 A 表是旧结果，尚未重算，不能据此确认物理方向性。
> D 中宽度翻倍为 21.70 M MACs，双视图为 11.33 M，二者不是等计算量；宽度翻倍接近四视图的 22.59 M。
> C/D 的原始分数保留。裁块负结果不等于完整检测器必然无效，也不取消普通方向增强对照。
> 当前主方法调整与实验协议见 [E013-v2](sardet100k_orientation_fusion_v2.md)。

日期：2026-11-12。接 [D17](sardet100k_d16_d17_source_orientation.md)。D17 发现冻结的检测器在垂直翻转的 val 图上掉 27 AP。这有两种解释：数据里有稳定的上下不对称，模型在利用它；或者模型只是没学过其他方向。前一种情况下，让各方向共享（[E013](sardet100k_orientation_fusion_design.md)）可能没有收益甚至有损失。用户要求在训练前先初步验证。

不使用检测器；只用 train 和 val 的 24×24 目标裁块（零均值、单位范数，与 D12 相同）。小 CNN 在 GPU 0 上各训练 6 轮。代码 `tools/sardet100k/orientation_cue_check.py`，输出 `d18_orientation_cue/`。

## 口径

- **A 像素统计。** 每个 GT 框内上半与下半的亮度差，以及框上方与下方条带的亮度差；左右作对比。看“上半更亮”的目标占比，train 与 val 分别统计。
- **B 翻转能否被认出。** 小 CNN 在 train 的裁块上学“这个裁块有没有被垂直翻转”，在 val 上测准确率（50% 是瞎猜）。对目标裁块和强杂波裁块（图中与目标同尺寸、最亮的背景框）各做一次；水平翻转作对比。
- **C 这个线索有没有用。** 同一个小 CNN 学“目标对强杂波”，训练时分别只用水平翻转（与检测器相同）、水平加垂直翻转、全部 8 个方向；在 val 的原方向上评估。指标是强杂波通过 1% 时的目标召回率。
- **D 结构本身。** E013 的缩小版：同一个主干看裁块和它的翻转视图，特征翻回后门控融合；与单视图、单视图加倍宽度比较。只用水平翻转训练，每种 3 个种子。
- **读法（运行前写在工具里，针对 C）：** 从“只用水平翻转”到“加垂直翻转”，原方向上的召回率下降超过 2 点，说明这个线索在裁块层面有用；1 点以内说明没用。

## 判定

按运行前写定的读法：**这个线索在裁块层面有用。** 加入垂直翻转后原方向上的召回率下降 2.5 和 3.7 点，超过 2 点的界线；用全部 8 个方向下降 4.1 和 5.9 点。

## 判读

1. **上下不对称是目标自身的性质，而且在 val 里稳定。** 多数来源的目标下半更亮（car 只有 10% 上半更亮），train 与 val 的比例几乎相同。只看一个 24×24 的目标裁块，就能以 78% 的准确率说出它有没有被翻转，aircraft 和 car 超过 91%。
2. **强杂波没有这个性质**（58%，接近瞎猜）。所以方向性本身就是区分目标和杂波的证据，这与 SAR 成像一致：有高度的人造目标朝向雷达一侧出现强回波，背向一侧是阴影，平坦的杂波没有。
3. **强行共享方向会损失。** 损失集中在方向性强的格子（224 aircraft −13.7，512 aircraft −5.1，car −4.8），OGSOD 的三类基本不变。这也预示“只加方向增强”的 E012 在 val 上会下降。
4. **E013 的结构在缩小版上没有收益。** 它避免了增强带来的损失（73.1 对 69–70），但也没有超过单视图（73.9），差值在种子波动范围内。同样的额外计算用在加宽上有 +2.7。
5. **OGSOD 的目标几乎没有方向性**（53–61%），方向共享对它们既不帮忙也不伤害。OGSOD tank 和 bridge 正是损失最大的格子，所以方向这条线帮不到它们。
6. **D17 的结论要改写。** “检测器锁定在方向上”仍然成立，但主要原因是它在使用一个真实且有用的线索，而不是泛化缺陷。D17 里“换方向能多检出 aircraft 和 bridge 的漏检”仍是事实，但在裁块层面没有转化成净收益。

## 对 E013 的含义

训练前检验不支持 E013。预期结果是与基线持平，计算量约 2 倍。它保留了原图一路，所以预期不会明显下降，但没有证据显示会上升。

## 局限

- 24×24 的归一化裁块，没有上下文，也不涉及定位；小 CNN 从头训练。真实检测器的容量和输入都不同。
- 强杂波取的是“最亮的同尺寸背景框”，与检测器自己的误检不是同一批。
- C 只有两次运行，D 是 3 个种子，种子间波动约 ±1。
- A 的统计不区分成像方向和标注框的系统性偏移；OGSOD tank 的不对称可能来自标注框相对目标的位置，这里不作解释。

# SARDet-100K 数据集画像

日期：2026-11-06。全部 116,598 张图、245,653 个目标，未抽样。脚本 `tools/sardet100k/dataset_profile.py`，结果在新服务器
`/root/zxy/experiments/diagnostics/sardet100k_dataset_profile_20261106/report.json`。只看标注和像素统计，不涉及 test 预测。

核心结论：**这个数据集的主要结构是来源，不是类别。同名类别在不同来源里可以是完全不同的目标；类别、尺寸、背景和灰度都和来源绑定。**

口径：
- 灰度是处理过的 8 位值，不是定标后的后向散射。“dB”只是灰度比。
- 没有分辨率、波段、极化等元数据。物理分辨率和成像条件只能用图像统计代理。
- 来源用像素比对得到（OGSOD、MSAR），其余按图像尺寸分组。`other_*` 只是尺寸分组，不等于单一来源。

## 6. 三个 split 的差异

**有差异，但主要是来源组成不同，不是同一来源内部的分布漂移。**

按图像的组成：

| 分组 | train | val | test |
| --- | ---: | ---: | ---: |
| MSAR | **26.8%** | 13.4% | 12.1% |
| OGSOD | 15.5% | 17.5% | 15.8% |
| other_256 | 33.6% | 37.9% | 34.2% |
| other_512 | 18.1% | 20.2% | **27.9%** |
| other_800 | **3.9%** | 9.4% | 8.5% |

- val 和 test 各来源图数几乎相同（OGSOD 1834/1833，MSAR 1409/1408，800 图都是 981），差异几乎只在 512 图：val 2120，test 3244。
- 目标级的影响：

| 指标 | train | val | test |
| --- | ---: | ---: | ---: |
| tank 中 OGSOD 占比 | 41.9% | 59.8% | **68.0%** |
| tank 长边 <16 | 42.1% | 59.5% | 68.4% |
| aircraft 中 MSAR 占比 | 14.7% | 2.2% | 4.2% |
| aircraft 长边 <16 | 18.1% | 4.4% | 7.7% |
| aircraft 占全部目标 | 20.5% | 22.9% | 28.0% |

- **训练集和评估集难度不同。** train 的 tank 大多是清晰圆环，评估集的 tank 大多是 OGSOD 小团块。这和 tank 随 OGSOD 占比上升、AP 从 val 57.66 到 test 53.91 方向一致。
- 尺寸 JS 散度相对随机划分的噪声底：aircraft 0.075/0.054 对 0.0006，tank 0.024/0.056 对 0.0015，其他类不到 0.01。
- 组成之外差异很小。同组内图像统计的标准化均差：MSAR、OGSOD、other_256 都不超过 0.06；other_512 最大，到 0.21。用图像统计区分 train 和 val/test，AUC 0.567/0.592，同分布对照 0.50。
- **重复：** 整图相关 ≥0.95 能在 train 中找到相似图的比例：val 29.3%，test 24.2%；目标裁片相关 ≥0.9：val 57.2%，test 50.4%。test 对 val 的整图匹配（≥0.95）是 5.0%。
- **test aircraft 比 val 低 13 点的线索（未证实）：** 多出来的 512 图都是 aircraft，test 的 aircraft 对比度更低（1.28 对 1.65 dB）、亮像素更少（8.8% 对 14.0%），每图目标更少。已有结果还显示，≥64 像素目标的裁片匹配率从 val 63.6% 降到 test 45.0%。这里只有分布证据，没有拆分 test 指标。

## 判读

1. 下结论时要按来源分组，全局中位数和全局 AP 都可能误导。
2. tank、bridge 难，不能只解释成“小”。OGSOD 的目标同时小、对比度低、背景有大量类似团块，这几个因素在这份数据里分不开。
3. 重采样或类别权重不太可能解决主要问题，因为 AP 不跟数量走。
4. 用 val 选方法时要注意，val 的 aircraft 比 test 容易，val 增益不一定能完整迁移到 test。

局限：来源标注靠像素比对，`other` 没有细分。所有“成像条件”都是代理量。相关不代表因果。
